Entry for the make.fun bounty [The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

`main.py` (Python 3.13, standard library only) writes one line — the error
message a kitchen toaster shows its owner when something goes wrong — to
`/output/entry.txt`:

> Error 12: I have toasted 4,112 slices since January. Not one said thank you. I quit.

Run it with:

```sh
python3 -P -s main.py
```
